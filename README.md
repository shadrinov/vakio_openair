# Диаграмма точки росы

Настольное приложение на Python с разрезом стены толщиной 450 мм: 330 мм полистиролбетона изнутри и 120 мм силикатного кирпича снаружи. Окно показывает температурный профиль и пунктирную линию там, где температура стены равна точке росы комнатного воздуха.

## Запуск

Требуется Python 3.10 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Начальные условия: +25 °C внутри, −20 °C снаружи, относительная влажность внутри 50%.

Температура внутри и снаружи, влажность внутри и теплопроводность обоих материалов меняются в окне; диаграмма обновляется сразу. Толщины слоёв сейчас фиксированы в `dewpoint/model.py`. Начальные значения теплопроводности (0,15 и 0,70 Вт/(м·К)) ориентировочные, их следует заменить на характеристики конкретных материалов.

Температурный профиль вычисляется по стационарной одномерной модели с поверхностными термическими сопротивлениями 0,13 и 0,04 м²·К/Вт. Точка росы воздуха вычисляется по приближению Магнуса. Пунктир на стене обозначает **условную изотерму**, а не доказанное место образования конденсата: для проверки увлажнения стены нужны паропроницаемость слоёв, влажность наружного воздуха и расчёт распределения парциального давления пара.

Источники для исходных оценок: [NOAA — формула точки росы](https://madis.ncep.noaa.gov/madis_rwis_qc_notes.shtml), [NORTEC — диапазон теплопроводности полистиролбетона](https://nortec.uz/en/main-properties), [Клинцовский силикатный завод — теплопроводность кирпича](https://www.k-silikat.ru/services/proizvodstvo-silikatnogo-kirpicha/). О различии между изотермой и анализом конденсации: [обзор UK Government](https://www.gov.uk/government/uploads/system/uploads/attachment_data/file/396363/solid_wall_insulation_literature_review.pdf).
